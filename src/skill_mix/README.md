# SkillMix 

Source: https://github.com/LeoYu/skill-mix/

This directory contains the public SkillMix data assets used in the SkillMix experiment:

- `skills.csv`: skill definitions used for dataset generation and grading.
- `topics_train.txt`: topic list used for ID evaluation.
- `topics_test.txt`: topic list used for OOD evaluation.
- `custom_utils/`: helper utilities used by scripts in `scripts/skill-mix/`.

The full reproducibility entrypoints are documented in the repository root [`README.md`](../../README.md).
